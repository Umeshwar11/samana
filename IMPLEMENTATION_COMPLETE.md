### Change Primary Color
```css

    --primary: #YOUR_COLOR;
}
```

### Change Fonts
```css
/* In css/typography.css */
@import url('https://fonts.googleapis.com/css2?family=YOUR_FONT');

:root {
    --font-heading: 'Your Font', serif;
```
